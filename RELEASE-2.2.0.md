# Kaelix 2.2.0

Minecraft **26.1.2** · Fabric Loader **0.19.5** · Fabric API **0.155.3+26.1.2** · Java **25**

Релиз по итогам полного аудита кода: новое меню модулей, собственные значки интерфейса и исправления ошибок. Поведение маршрутов, Motion, Combat/Hunting, AutoFish и проверок паники **не менялось**; формат конфига прежний.

## Главное
- **Каталог модулей сеткой**: компактные карточки в 2–3 колонки вместо одной карточки на экран.
- **32 собственных значка интерфейса** (`textures/gui/icons.png`, генератор `tools/gen_ui_icons.py`) на кнопках, в поиске, заголовках разделов и боковой панели.
- **Поиск и клавиатура**: Ctrl+F, очистка поиска, Home/End, клик по дорожке прокрутки.
- **Сборка снова проходит**: удалены файлы, вернувшиеся после загрузки через веб-интерфейс GitHub.
- **Приватность**: код настроек и отчёт об ошибке не содержат списки друзей, ключевые слова чата и имя цели.
- Исправления в меню, текстовых полях, маршрутах, кэше чанков, конфиге, истории запусков, Discord и оконных режимах — полный список в `CHANGELOG.md`.

## Установка
Замените старый JAR на `kaelix-2.2.0.jar`. Конфиг `config/farmmacro/` остаётся как есть.

## Проверка
`./gradlew build compileStressJava` (Error Prone/NullAway, Spotless, JUnit) и `runClientGameTest` под Xvfb (скриншоты всех экранов меню при окне 854×480). Широкая раскладка меню (окно ≥ 540 единиц GUI) проверена только модульными тестами геометрии. Hypixel, сеть, Discord и звук не проверялись.

## При загрузке через веб-интерфейс GitHub
«Add files» не удаляет старые файлы. Удалите пути из разделов 2.0.2, 2.1.0 и 2.2.0 файла `REMOVED-FILES.txt`, иначе `./gradlew build` остановится на `checkRemovedFiles`.
